# 💰 Семейный Бюджет / Family Budget

> Приложение для контроля бюджета семьи в стиле Frutiger Aero для Android

## ✨ Особенности

| Функция | Описание |
|---|---|
| 👨‍👩‍👧 Семейные аккаунты | Несколько пользователей на одном устройстве, у каждого свой бюджет |
| 🔒 PIN-защита | Необязательный 4-цифровый PIN для каждого аккаунта |
| 💵 Операции | Доходы и расходы с категориями и примечаниями |
| 📅 Бюджет | Лимиты расходов по категориям с индикатором выполнения |
| 📈 Отчёты | Круговая диаграмма расходов по категориям |
| 🎨 Frutiger Aero | Глянцевые панели, глоссовые кнопки, цветовые аватары |

## 🛠 Технологии

- **язык**: C++17
- **UI фреймворк**: Qt 6.7 + QML
- **База данных**: SQLite (через Qt SQL)
- **Сборка**: CMake + Android NDK
- **Платформа**: Android 7.0+ (API 24+)

## 🚀 Сборка

### Локальная сборка (Qt Creator)

1. Установите [Qt 6.7+](https://www.qt.io/download) с модулем Android
2. Установите Android SDK + NDK (API 24+)
3. Откройте `CMakeLists.txt` в Qt Creator
4. Выберите устройство/эмулятор Android
5. Соберите и запустите

### CI/CD (автоматическая сборка)

Kaждый push в `main` или `claude/**` запускает сборку.

### Создание релиза

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions автоматически соберёт APK и опубликует релиз.
